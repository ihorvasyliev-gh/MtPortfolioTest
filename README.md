# Mariia Troian — сайт-портфолио с админкой

Сайт работает на **Cloudflare Pages** (проект `mariia-troian`, https://mariia-troian.pages.dev) + **R2** (хранилище фото) + **D1** (статистика визитов). Мария редактирует сайт на `/admin`.

```
public/            статика: style.css, script.js, compcard.js, шрифты (fonts/), Lenis (vendor/),
                   favicon, стартовые фото (assets/), админка (admin/)
src/worker.js      сервер: вход, API админки, отдача фото из R2, отдача страницы
src/render.js      собирает HTML страницы (а также 404 и sitemap.xml) из контента
src/content.js     проверка/очистка данных, которые присылает админка
src/default-content.json   стартовый контент (используется, пока в R2 нет content.json)
wrangler.jsonc     конфигурация Cloudflare
```

## Как это устроено

- Весь редактируемый контент (тексты, список фото, порядок, категории) лежит одним файлом `content.json` в R2.
- Фото лежат в R2 в папке `photos/`. Браузер Марии **сам уменьшает** фото перед загрузкой (до 2200 px + превью 900 px, WebP), поэтому снимки с телефона на 8 МБ грузятся быстро, а на сайте открываются мгновенно.
- Страница `/` собирается на сервере из `content.json` — Google и превью ссылок в соцсетях видят настоящий текст и фото.
- Изменения в админке попадают на сайт после нажатия **Publish**.
- Стартовые 22 фото лежат в `public/assets/` и работают сразу; Мария может скрыть или удалить любое из них в админке (файл в репозитории при этом остаётся).

## Дизайн и анимации

- Интро с монограммой при первом заходе (один раз за сессию), затем имя в hero появляется по буквам, фото раскрывается «шторкой».
- Плавный инерционный скролл ([Lenis](https://github.com/darkroomengineering/lenis), лежит в `public/vendor/`), параллакс, заголовки выезжают по словам, линии прорисовываются, цифры в параметрах «досчитываются».
- Галерея: masonry в порядке, заданном в админке; при смене фильтра плитки плавно переезжают; лайтбокс раскрывает фото прямо из плитки, листается стрелками, клавишами и свайпом, свайп вниз закрывает.
- На компьютере: свой курсор («View» над фото), «магнитные» кнопки, лёгкая реакция hero на мышь.
- Всё без тяжёлых библиотек, кроме Lenis (~18 КБ). Если в системе включено «уменьшить движение» или скрипт не загрузился, сайт показывается сразу целиком, без анимаций.
- Шрифты (Cormorant Garamond, Jost, лицензия OFL) раздаются с самого сайта, без Google Fonts: быстрее и без передачи IP посетителей в Google (GDPR).

## Comp card (PDF)

Кнопка **Download comp card** на сайте (в блоке Measurements и в контактах) собирает PDF прямо в браузере посетителя (`public/compcard.js`): обложка с именем и 4 фото на обороте с параметрами и кликабельными контактами. PDF всегда совпадает с тем, что сейчас опубликовано.

Фото для comp card выбираются в админке: **Measurements → Comp card**. Там же можно посмотреть и скачать PDF до публикации. Пустые места заполняются автоматически (обложка — главное фото).

> Если включите `IMG_BASE` (раздача фото с отдельного домена R2), добавьте в бакете R2 → Settings → **CORS policy** разрешение `GET` для адреса сайта, иначе браузер не даст нарисовать фото в PDF.

## Деплой (Cloudflare Pages)

```bash
npm install
export CLOUDFLARE_API_TOKEN=...  CLOUDFLARE_ACCOUNT_ID=...   # либо `npx wrangler login`
npm run deploy
```

`npm run deploy` (`scripts/deploy-pages.sh`) собирает `public/` + `src/worker.js` (как `_worker.js`) во временную папку и выкладывает в Pages-проект `mariia-troian` (ветка `main`).

Привязки и секрет живут в настройках Pages-проекта (Workers & Pages → mariia-troian → Settings → Bindings / Variables and Secrets):

| Привязка | Что | Ресурс |
|---|---|---|
| `BUCKET` | R2 | `mtportfolio-photos` — фото и `content.json` |
| `DB` | D1 | `mtportfolio-stats` — визиты; таблица создаётся сама при первом визите |
| `ADMIN_PASSWORD` | секрет | пароль админки |

Сменить пароль: `npx wrangler pages secret put ADMIN_PASSWORD --project-name mariia-troian` (старые сессии сразу станут недействительны).

Свой домен: Workers & Pages → mariia-troian → Custom domains → Set up a custom domain.

`npm run setup` / `npm run deploy:worker` — старый вариант установки на Cloudflare **Workers** (создаёт бакет, Worker и пароль, переносит стартовые фото в R2). Для текущего сайта на Pages не нужен.

## Статистика визитов

Вкладка **Visits** в админке: посетители и просмотры по дням, источники (Instagram, Google…), страны и города, устройства, браузеры, самые просматриваемые фото, скачивания comp card и клики по email/Instagram, последние визиты.

- Без cookie и без IP: посетитель — это хэш (день + IP + браузер + секрет), он меняется каждый день и не обратим. Поэтому баннер согласия не нужен.
- Не считаются: боты, визиты из браузера, где выполнен вход в админку, браузеры с Do Not Track / Global Privacy Control.
- Данные хранятся 400 дней. Код: `src/stats.js` (сервер), `track()` в `public/script.js` (браузер).

```bash
echo 'ADMIN_PASSWORD=test' > .dev.vars

```

## SEO и прочее

- `/robots.txt` и `/sitemap.xml` формируются сервером с текущим доменом; несуществующие адреса отдают оформленную страницу 404.
- У страницы есть canonical, Open Graph (превью ссылок в соцсетях) и разметка schema.org `Person`.

## Безопасность

- Вход по паролю (`ADMIN_PASSWORD`), сессия 30 дней в `HttpOnly`/`Secure`/`SameSite=Strict` куке; неверный пароль замедляется на ~1 с.
- Все записи проверяются сервером (`src/content.js`): допускаются только свои пути к фото, весь текст экранируется при выводе.
- Загрузка принимает только JPEG/WebP до 6 МБ.
- Хотите ещё надёжнее — закройте `/admin/*` и `/api/admin/*` через **Cloudflare Access** (Zero Trust, бесплатно до 50 человек): вход по коду на почту Марии, без паролей.
- Сменить пароль: `npx wrangler pages secret put ADMIN_PASSWORD --project-name mariia-troian` (все старые сессии сразу станут недействительны).

## Раздача фото напрямую из R2 (по желанию)

По умолчанию фото отдаёт Worker (`/img/...`) с кэшем на год. Чтобы отдавать их напрямую с CDN: R2 → бакет → Settings → Custom Domains (например `photos.example.com`) и добавить переменную `IMG_BASE=https://photos.example.com` в настройках Pages-проекта.
